# LocalSMS

یک برنامهٔ سادهٔ Android برای ارائهٔ پیامک‌های گوشی از طریق Local Web.

## نیازمندی‌ها
- Android 6+
- مجوز READ_SMS
- اتصال Wi-Fi برای دسترسی از دستگاه دیگر

## ساخت
پس از Push کردن پروژه به GitHub، از بخش Actions workflow با نام **Build LocalSMS APK** را اجرا کنید.

APK ساخته‌شده در Artifacts قرار می‌گیرد.

## استفاده
1. APK را نصب کنید.
2. مجوز SMS را تأیید کنید.
3. روی «شروع Local Web» بزنید.
4. آدرس نمایش‌داده‌شده را در مرورگر دستگاه متصل به همان شبکه باز کنید.
5. برای خواندن SMS روی «نمایش پیامک‌ها» بزنید.

### نکتهٔ امنیتی
این برنامه برای نمونه و شبکهٔ محلی ساخته شده است. هر کسی که هم به شبکهٔ محلی دسترسی داشته باشد و هم توکن نشست را داشته باشد می‌تواند SMSها را ببیند. سرور را روی شبکهٔ عمومی یا اینترنت قرار ندهید.
